# SOC Monitoring System using Splunk

## Overview

This project demonstrates a basic SOC (Security Operations Center) monitoring setup using Splunk in a controlled lab environment.
The system was used to collect, monitor, and analyze logs for identifying suspicious activities and understanding security event monitoring workflows.

---

## Objectives

* Understand SIEM and SOC monitoring concepts
* Collect and analyze logs using Splunk
* Monitor security events and suspicious activities
* Explore basic log analysis and event investigation

---

## Tools Used

* Splunk Enterprise
* Kali Linux / Windows VM
* Virtual Machine Lab Environment
